# Boat Register

*The race office's paper table. It is the registration list, the race order and the documentation at the same time. See [Registration and race office](../wiki/17-Race-Office.md).*

**Event:** _[village, date]_ · **List:** ☐ Kids and teens (0–18) ☐ Grown-ups (over 18) · **Sheet** ___ of ___

**How to use it:**

- Register boats in the order they arrive. **Each block of three rows is one heat**, and the blocks are called one after the other.
- Write the **boat name** only, never the names of the builders.
- **Two separate lists:** one for kids and teens (0–18), one for grown-ups (over 18). Use differently coloured ticket rolls.
- Start number = number of the cloakroom ticket on the boat. **Kids:** the tear-off stub is the ice cream voucher, **one per child**; for a child's second and further boats, tear off the stub and keep it. **Grown-ups:** remove the stub; tick the start fee in the 🍦/€ column.
- Before writing: *"Is your boat finished? After registration, it stays as it is."*

Prize columns: 🏁 Fastest · 🐢 Underdog · 🏋️ Heaviest · 🗼 Tallest · ❤️ Audience · _[sponsor prize]_ · _[sponsor prize]_. Adapt them to your prize catalogue.

## Filling in

| Field | When | How |
|---|---|---|
| No. | Registration | Number of the cloakroom ticket |
| Boat name | Registration | As the builder says it. No names of people |
| A4 ✔ | Registration | Fits on the A4 gauge |
| Weight | Registration | Kitchen scale, dry boat, with its number, in grams |
| Height | Registration | Lowest to highest point, standing upright, in cm |
| Time | Race | mm:ss at the finish line |
| 🍦/€ | Registration | **Kids:** ✔ if the stub (ice cream) was handed out, ✗ if removed because the child already has one. **Grown-ups:** ✔ start fee paid |
| DSQ | Race | ✗ if disqualified (sunk, or stuck / capsized again after its one rescue). Write "R" if the builder used the rescue, e.g. for the Iron Raven prize |
| Prize columns | After the last race | Tick the winner. This is your documentation |

## Optional columns

- **Photo nos.** from the photo station
- **Main materials**, for the statistics and the online gallery
- **Talers** counted per boat
