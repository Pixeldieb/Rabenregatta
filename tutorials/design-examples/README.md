# Design Examples: Study Boats

Three study boats, each showing one building principle. They're here so you can **understand** how things work, not to copy them.

> ⚠️ **Study, don't copy.** A copy of a study boat may not race. Use them as a starting point for questions: *What would I do differently? What would work better on our creek?*

| Study boat | Principle | Main materials | Difficulty |
|---|---|---|---|
| [Cork raft](cork-raft.md) | Floating with low-density material | Wine corks, skewers, string | ⭐ Easy (from age 6) |
| [Carton catamaran](carton-catamaran.md) | Stability through width | Drink cartons, sticks, cloth | ⭐⭐ Medium (from age 8) |
| [Offcut keelboat](offcut-keelboat.md) | Going straight with a keel and a pointed hull | Wood offcuts, dowel, cotton cloth | ⭐⭐⭐ Harder (from age 10) |

## Add your own study boat

Did you discover a great principle? Write it up using this structure:

```markdown
# Study boat: [Name]

**Principle:** ...
**Materials:** ... (traffic light colour for each)
**Tools:** ...
**Difficulty:** ⭐ / ⭐⭐ / ⭐⭐⭐

## The idea
## How it works
## Building notes
## Testing
## Questions to take further
```
