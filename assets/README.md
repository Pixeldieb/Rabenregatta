# Assets

Images, logos and drawings for Rabenregatta.

## Structure

```text
assets/
├── logo/                  ← Rabenregatta logo (SVG + PNG)
├── images/
│   ├── design-examples/   ← photos of study boats (boats only, no faces)
│   ├── equipment/         ← start board, catch net, A4 gauge, Euroboxes
│   └── events/            ← photos from events (only with consent!)
├── drawings/              ← construction drawings, site map templates
└── icons/                 ← box colour icons, traffic light symbols
```

## Rules for uploads

- **Consent first.** Only upload photos of people if everyone shown (for children: their guardians) agreed to publication in this repository.
- **Prefer boats over faces.**
- **Size:** compress photos to max. 1600 px on the long side, JPG or WebP.
- **Formats:** logos and drawings as SVG if possible; Markdown can show SVG and PNG.
- **Name files clearly:** `2027-ourvillage-start-board.jpg`, not `IMG_4711.jpg`.
- **License:** by uploading, you agree to share under CC BY-SA 4.0 (see [LICENSE](../LICENSE.md)). Mention the photographer in the file name or in a `CREDITS.md`.
